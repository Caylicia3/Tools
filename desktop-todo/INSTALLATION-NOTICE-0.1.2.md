# 0.1.2 安装与 360 提示说明

更新日期：2026-10-15。状态：用户确认，在该 Windows 11 电脑上允许 360 安装操作后，可以正常安装、正常打开，打开时没有再出现 360 警告。

安装过程中仍可能出现 360 防护提示。上述结果仅覆盖这台电脑的本次操作，不表示所有电脑安装时都不会提示，也不表示用户切换到可选的系统通知模式后仍不会提示。

## 本次反馈与复测

1. 用户卸载旧程序后重新安装 0.1.2，没有处理 360 文件防护提示。截图中的默认操作为“阻止本次操作”。
2. 安装器替换 DesktopTodo.exe 时出现 MoveFile 失败、错误代码 5；用户选择“跳过此文件”继续，随后保存桌面快捷方式时出现 IPersistFile::Save 失败、0x80070005。
3. 用户重新测试并允许 360 安装操作后，确认安装和打开正常，打开时没有 360 警告。

这些反馈支持“安装操作被安全软件阻止，跳过失败文件后安装可能不完整”的判断。没有为本次复测更换程序包或修改代码；不将这个结果描述为发布了新的修复版本。

安装阶段的文件防护与应用启动阶段的通知注册属于不同操作。0.1.2 默认使用托盘提醒；设置中显式选择的系统通知仍需注册 Windows 通知入口。

## 安装时遇到提示怎么办

1. 使用本仓库 Release 的完整安装包，可用随附 SHA256SUMS-0.1.2.txt 核对文件。升级前完全退出旧程序，保留原数据目录。
2. 如果 360 提示安装器修改本程序的 exe 或快捷方式，先核对发起程序、目标和刚执行的安装操作是否一致，确认后仅允许本次操作。不确定时先取消并核对文件。
3. 若安装器仍报错，不要选择“跳过此文件”。取消后保留错误信息和安装日志，再排查。不要删除原日程数据。
4. 不需要关闭全部防护或给整个磁盘加白名单。

可通过安装器的 /LOG="完整日志路径" 参数记录文件安装与错误步骤；/LOGCLOSEAPPLICATIONS 记录占用程序检测详情。日志可能包含 Windows 用户名和本机路径，回传前可查看；不要公开上传日程数据库。

官方参考：[Windows 错误代码](https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--0-499-)；[Inno Setup 安装日志参数](https://jrsoftware.org/ishelp/topic_setupcmdline.htm)；[360 软件误报反馈](https://open.soft.360.cn/report.php)。是否申请厂商审核需另行决定，本次没有向 360 提交文件或改变安全软件设置。
