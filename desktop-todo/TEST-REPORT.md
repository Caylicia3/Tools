# 日程管理 0.1.1 · 测试说明

本次发行面向 Windows 11 x64，以下记录已完成的本地验证范围。

## 验证环境

- Windows 11 x64，系统版本 10.0.26200.9457。
- 实际显示缩放为 150%。
- WPF / .NET 10；应用与运行组件一同分发。
- 版本 0.1.1.0，程序仅手动启动。

## 已完成检查

- 核心逻辑 56 项通过、0 项失败：日期计算、重复日程、重叠排布、校验、数据保存与恢复、提醒和撤销重做。
- 周／月缩放、缩放后的新增和拖动、任务时间轴范围、节点移动预览和确认。
- 四套主题、有效与无效颜色输入、外观实时预览、保存与取消还原。
- 不同任务条粗细、行高、小窗口和密集重叠布局。
- 拆分／合并、任务栏最小化与恢复、主面板退出入口和编辑窗口取消。
- 自选安装位置、既有数据位置保留、升级和卸载保留数据。
- 免安装版完整解压后的启动与退出。
- 桌面快捷方式显示名称与实际启动；用户已在验证环境中确认双击可打开。

## 覆盖范围说明

- Windows 10、其他系统 DPI、多显示器混合 DPI和长期连续运行未完成完整实机验证。
- 实机结果不代表已覆盖所有电脑、系统配置和任意规模的数据。
- 不在公共仓库发布个人数据库、测试截图或本机诊断日志。
