## 本次源码整理的本机回归

2026-10-15，Windows 11 x64、.NET SDK 10.0.302，使用 E 盘独立演示数据完成 `--smoke --interactions --update-checks`，结果 `passed: true`，测试进程正常退出。

- 四套主题、设置和编辑窗口颜色同步，实时预览、取消恢复，条形粗细与行高独立调节。
- 周／月缩放及比例记忆；缩放后的点击、日程移动、时长调整、80 项密集重叠及撤销／重做。
- 节点预览、松手保存、撤销，以及 Esc、越界、同日期不提交；任务条保持不可拖动。
- 任务与节点独立关闭提醒；最大化／还原、拆分合并、任务栏入口、最小化恢复。
- 时间轴拖动与底部滚动条的实时日期定位，范围同步；视口变化不进入内容历史。
- 小窗口、桌面驻留与置顶切换、备份恢复。

回归脚本的原拖放模拟依赖 UI 线程继续执行释放鼠标，可能在原生拖放循环中失效。本次改为预先计算屏幕坐标，由工作线程发送完整手势；检查仍实际移动鼠标并验证结果，没有改动程序的拖动处理逻辑。

本次源码整理核对了 C# 语法标记及项目 XML：除上述交互测试脚本外，16 个 C# 文件的语法标记和 3 个项目文件的配置语义保持不变。截图来自独立演示数据。上述回归不替代其他电脑的兼容性验证。
