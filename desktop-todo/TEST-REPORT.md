# 测试与验证范围

本页区分当前源码的自动检查和已发布版本的实机验证。**构建成功不等于界面与所有电脑均已验证。**

## 当前源码

| 检查 | 方法 | 结果位置 |
| --- | --- | --- |
| 应用编译 | `build.ps1 -Action build` | 构建输出、Actions 日志 |
| 核心逻辑 | `build.ps1 -Action test` | PASS／FAIL 明细及 `.tmp/tests/results.txt` |
| 格式 | `build.ps1 -Action format-check` | 检查退出码及 Actions 日志 |

[查看 GitHub Actions](https://github.com/Caylicia3/Tools/actions/workflows/desktop-todo-ci.yml) · [本地复现方法](docs/DEVELOPMENT.md)

核心检查包括跨年闰日、每周重复及例外、重叠排布、提前提醒、独立提醒开关、去重、SQLite 保存、备份恢复、100 步历史、失败回滚，以及缩放和平移的日期计算。当前基线为 **60 项**；实际运行结果以相应提交的日志为准，不将数量视为覆盖率。

2026-10-15 整理前基线：Windows 11 x64、.NET SDK 10.0.302，60 项通过，编译零警告、零错误。本地基线使用已准备的离线依赖；GitHub Actions 从 NuGet 独立恢复依赖。
