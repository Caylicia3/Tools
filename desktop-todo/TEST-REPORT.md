# 日程管理 0.1.2 · 测试说明

本地验证日期：2026-10-14；用户实机反馈更新：2026-10-15。本文件记录已完成的源码、核心逻辑、界面验证及用户回测反馈；安装包和交付核验结果记录在单独提供的 ACCEPTANCE-0.1.2.md 中。

## 环境

- 本地：Windows 11 x64，Build 26200，显示缩放 150%。
- .NET SDK 10.0.302，WPF / .NET 10，自包含发行。
- 所有测试数据使用 E 盘独立目录，未用于正式日程。
- Windows 10 22H2 19045.2965：用户提供了 0.1.1 CET 单项兼容测试报告，并确认面板能显示、点击和操作正常。这只证明该兼容方式在该电脑可用，不等于 0.1.2 全功能已在该电脑验收。

## 已完成

- 60 项核心检查通过、0 失败：重复日程、重叠排布、日期和闰日、提前提醒、去重、任务/节点分别关闭提醒、SQLite 保存、备份恢复、100 步历史和失败回滚。
- 节点拖动实时预览、有效松手直接保存、撤销；Esc、移出区域、越过任务范围、回原日期均不提交；拖动时暂停缩放。
- 任务条保持不能移动和拉伸。
- 日期刻度/空白区域拖动平移：左右、空范围、Esc、丢失鼠标捕获、缩放锁定；任务和节点真实日期及内容撤销记录不变。
- 底部原生横向滚动条：拖动滑块实时改变日期范围，与界面同步，不修改任务数据。
- 任务、节点的“不提醒”选项互不影响；关闭时禁用时间输入，不完整输入不会阻止保存关闭状态，已有有效提醒参数保留。
- 两个面板在桌面模式和浮动模式下最大化到当前屏幕工作区，保留任务栏；还原恢复尺寸和位置；最大化后最小化再恢复仍为最大化。
- 原有周/月缩放、缩放后点击/拖动/调整时长、四套主题、实时外观预览、取消还原、小窗口和密集重叠。
- 实际任务栏入口、Win+D 最小化、任务栏点击恢复、拆分合并、置顶切换。
- 默认托盘提醒发送路径通过；启动默认不调用 Windows App SDK 通知注册。系统通知为显式可选项。
- 兼容版在本地 Windows 11 完成新增功能的界面回归。
