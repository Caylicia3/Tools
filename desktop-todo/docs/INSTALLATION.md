# 安装 FAQ

## 下载哪个文件？

优先选择标准版 `Setup.exe`。若标准版在支持的 x64 Windows 上无法启动，可以尝试文件名含 `Compatibility` 的对应版本。兼容版关闭本程序启动文件的 CET 标记；两版功能与数据格式相同，不需要同时安装。

ZIP 免安装版需要**完整解压**后运行 `DesktopTodo.exe`。不要只复制一个 exe，也不要把 GitHub 的 Source code 压缩包当作安装包。

## 程序、数据与源码为什么分开？

安装器分别选择程序目录和数据目录。数据不能放在程序目录里面，以免升级或卸载程序时影响日程。

普通安装不会下载开发工程、编译工具或测试缓存。源码目录仅供开发使用。升级沿用数据位置，卸载保留数据；清理数据前应先在程序内导出备份。

## 安装被安全软件阻止怎么办？

部分 360 环境可能询问是否允许安装器写入本程序文件或快捷方式。先确认安装包来自 [本仓库 Release](https://github.com/Caylicia3/Tools/releases/tag/desktop-todo-v0.1.2)，并核对提示的发起程序、目标文件与正在执行的安装操作；确认后可仅允许本次预期操作。

如果安装器出现“拒绝访问”，请取消安装并处理对应提示后重试，**不要选择“跳过此文件”继续安装**。无需关闭全部防护。若明确允许后仍失败，应继续检查文件占用、目录权限或安装日志，而不是假定所有拒绝访问都由安全软件造成。

已记录的一台测试机在允许安装操作后安装、启动正常。该结果不是所有环境均无提示的保证。

## 双击没有反应怎么办？

确认系统为支持的 x64 Windows，ZIP 已完整解压，并检查任务栏、托盘是否已有程序实例。若标准版仍无法启动，可试兼容版；仍失败时通过 Issue 提供系统版本、所用包名、复现步骤与错误信息。

更新安装前，通过主面板“×”退出整个程序；“—”只是最小化。

## 提醒需要联网或开机自启动吗？

不需要联网，程序使用本机系统时间。不添加开机启动项，退出程序后不继续提醒；下次启动会汇总错过的提醒。

默认使用托盘提醒。设置中的“系统通知”需要注册 Windows 通知入口，可能触发额外的安全软件提示；这与安装器写文件是不同操作。

## 如何提供安装日志？

可以在 PowerShell 中运行：

```powershell
& '.\DesktopTodo-0.1.2-win-x64-Setup.exe' '/LOG=E:\Temp\DesktopTodo-install.log'
```

将示例改为实际安装包位置和可写的日志路径，提前创建日志目录。日志可能包含用户名及路径；提交前检查内容，不要上传个人日程数据库。

参考：[Inno Setup 日志参数](https://jrsoftware.org/ishelp/topic_setupcmdline.htm)。
