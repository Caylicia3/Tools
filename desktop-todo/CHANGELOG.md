# 更新记录

本页按用户可见行为记录发行变化。构建、文档与格式整理记录在 Git 提交和 Pull Request 中。

## 0.1.2 · 2026-10-15 · 预览版

- 增加最大化／还原按钮，铺满屏幕工作区并保留任务栏。
- 时间轴增加底部滚动条及空白区域拖动浏览。
- 节点拖动保留日期预览，松手直接保存，可撤销。
- 任务与节点分别支持“不提醒”。
- 默认使用托盘提醒，保留可选系统通知。
- 提供标准版和启动兼容版。

[下载与版本说明](https://github.com/Caylicia3/Tools/releases/tag/desktop-todo-v0.1.2)
