# 更新记录

本页按发布版本记录用户可见变化。构建、测试和实现细节见对应提交及验证说明。

## 0.1.3.2 · 2026-10-18 · 预览版

- 新增待办清单与自由笔记侧栏，支持逐字字号、文字颜色、独立书写背景、两区缩放和自动保存。
- 清单支持完成勾选、排序、隐藏已完成项；侧栏内容纳入共享100步撤销历史及备份。
- 侧栏使用外侧附属窗口，拉动时日程与任务时间轴的位置、尺寸和图表宽度保持不变。
- 支持独立显示、拖动停靠、日程／时间轴之间合并，随宿主移动、最小化和恢复。
- 采用无文字圆角把手。右侧空间不足时使用左侧；两侧空间都不足时提示先还原或移动主窗口。
- 保留原有数据格式、手动启动、托盘提醒及标准／兼容构建机制。

## 0.1.2 · 2026-10-15 · 预览版

- 增加最大化／还原按钮，铺满屏幕工作区并保留任务栏。
- 时间轴增加底部滚动条及空白区域拖动浏览。
- 节点拖动保留日期预览，松手直接保存，可撤销。
- 任务与节点分别支持“不提醒”。
- 默认使用托盘提醒，保留可选系统通知。
- 提供标准版和启动兼容版。

[下载与版本说明](https://github.com/Caylicia3/Tools/releases/tag/desktop-todo-v0.1.2)
