# 参与和反馈

欢迎报告可复现的问题、讨论使用场景或提交小范围改动。项目为个人维护，暂不承诺固定更新周期。

## 问题反馈

先查看 [安装 FAQ](docs/INSTALLATION.md)。提交 Issue 时说明系统版本、程序版本、标准版或兼容版、复现步骤及预期／实际结果。请检查日志与截图中的个人信息，不要提交日程数据库。

## 代码修改

1. 按 [开发说明](docs/DEVELOPMENT.md) 构建并运行核心检查。
2. 一次 PR 聚焦一个问题；格式整理与行为变更分开提交。
3. 描述触发条件、修改后的行为、验证结果和未覆盖情况。
4. 界面变更附使用虚构数据的程序截图；不要公开个人桌面或日程。
5. 提交前运行 build、test 和 format-check。新增测试应验证实际边界或失败行为，不只重复实现步骤。

新增依赖、数据格式变化或桌面驻留方式变化，请先通过 Issue 讨论影响。保留第三方许可与署名；提交到本子项目的可授权改动按其 MIT 许可提供。

公共仓库不应包含凭据、数据库、开发缓存、诊断日志或编译产物。
